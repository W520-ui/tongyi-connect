## 通读项目「通译智联」（华创杯参赛项目，D:/华创杯）

- 定位：面向中小跨境商家的多语言客服工作台，演示闭环为「海外咨询 → 意图识别 → 商品检索 → 多语言回复 → 商家中文摘要 → 售后人工接管 → 数据看板」。
- 前端：Vue 3 + TS + Vite + Pinia + vue-router，`src/services/*` 用原生 fetch 封装（`/api` 前缀，Agent 超时 70s）；页面 `/workspace`（聊天面板 + 流程监控 + 商品库 + 统计 + 接管队列 + 归档）、`/settings`（健康检查 + 演示脚本）、404。Vite 把 `/api` 代理到 127.0.0.1:8000。
- 后端：FastAPI（Python ≥3.11），`/api/v1` 下 health / agent/chat / catalog / dashboard 系列端点。`AgentService` 先分析消息，再按配置调用 AstrBot `POST /api/v1/chat`（X-API-Key，SSE plain/complete 事件聚合）；无 Key、连接失败或模型不可用时降级到 `app/services/workflow.py` 的关键词规则（语言、意图、3 个商品、中/英/西话术、售后转人工）。
- 数据：`backend/data/workflow.db`（SQLite，全局 `WorkflowMetrics` 单例），按 session_id 记忆上一轮商品；看板统计、最近归档、接管队列与确认接管都读写它。
- 运行：`npm run dev` 通过 `scripts/dev-all.mjs` 同起前后端（依赖 `backend/.venv`）；`npm run build`；后端测试 `cd backend && ./.venv/Scripts/python.exe -m unittest discover -s tests -v`。
- 验证：7 个后端单测全部通过；`backend/.env` 已填写 ASTRBOT_API_KEY、DEBUG=true、AGENT_LOCAL_FALLBACK_ENABLED=true；workflow.db 已有 2 条归档会话。
